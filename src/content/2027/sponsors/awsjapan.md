アマゾン ウェブ サービス（AWS）は、2006年にウェブサービスという形態で、企業を対象にITインフラストラクチャのサービス提供を開始しました。
日本では 2010年より AWS ユーザーコミュニティであるJAWS-UG (Japan AWS User Group) の支援を開始、 2011年の東京リージョン、 2018年の大阪ローカルリージョン開設し、AWSジャパンは日本のお客様とともに成長を続けてまいりました。 これからも AWS はユーザーそしてユーザーコミュニティとともにイノベーションを追い求め、新しい社会を作るお手伝いをしていきます。
